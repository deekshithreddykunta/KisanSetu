# KisanSetu

KisanSetu is an agricultural digital platform that directly connects farmers, FPOs, consumers and bulk buyers.

## Technology Stack

- Frontend: React.js
- Backend: Node.js + Express.js
- Database: PostgreSQL
- AI/ML: Python
- API: REST API
- Authentication: JWT

## Main Features

- Farmer Management
- FPO Management
- Consumer Marketplace
- Bulk Buyer Marketplace
- Preorders
- Demand Forecasting
- Demand Commitment
- Farmer-Buyer Matching
- Fair Price Engine
- Supply Risk Prediction
- Self-Healing Supply Network
- Quality Passport
- Logistics Optimization
- Shelf-Life Prediction
- Produce Rescue
- Fertilizer Advisor
- Fraud Detection
- Market Anomaly Detection
- Agricultural Digital Twin
- Admin Dashboard
